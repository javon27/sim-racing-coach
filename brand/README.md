# Nestor — brand marks

- `helm-color.svg` — primary colorized mark: near-black shell `#141218`, bronze crest `#B0824A`, accent-purple visor `#6D4AFF`. Used in-app (see `frontend/src/lib/NestorMark.svelte`) and marketing.
- `helm.svg` — flat one-color silhouette (`currentColor`) for favicons and one-ink contexts.

Wordmark: **Outfit** (SIL OFL). App icons in `src-tauri/icons/` are generated from the color mark on a light tile.
