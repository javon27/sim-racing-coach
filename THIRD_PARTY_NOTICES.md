## Dependencies
The full license texts of everything below ship with the installer as
`THIRD_PARTY_LICENSES.txt`, generated by `scripts/third_party_licenses.py` (CI
reruns it before every installer build). This overview was generated 2026-10-18. To regenerate, run `pip-licenses` over the runtime closure,
`cargo metadata` in `src-tauri/`, and `npx license-checker --production` in `frontend/`.
GPL-licensed code is not shipped: kokoro-onnx's `phonemizer`/`espeakng-loader`
dependencies are deliberately left uninstalled (see `CLAUDE.md`), and PyAV (whose
wheel bundles GPL x264/x265) plus ctranslate2's NVIDIA cuDNN DLL are excluded from
the frozen sidecar (`packaging/simcoach-sidecar.spec`). Build-only tools
(PyInstaller, Vite, Svelte compiler, vitest) are not listed.
