# Backlog

Open work is tracked in **GitHub Issues** — the single source of truth:
https://github.com/javon27/sim-racing-coach/issues

Handy filters:
- `area:coach` / `area:tracks` / `area:ui` / `area:capture` / `area:infra` — where it lives
- `rig-verify` — needs a live eyeball at the rig
- `bug` / `enhancement` / `chore` — kind of work
- `future` — roadmap, not scoped yet
- `deprioritized` — parked by the #99 course-correct, revisited only when a coaching feature needs it

Other trackers, so nothing overlaps:
- **`docs/vision.md`** — the north star / product direction (not a task list).
- **`docs/superpowers/specs/`** and **`docs/superpowers/plans/`** — design specs and
  implementation plans (linked from issues where one exists).
- **Project memory** (auto-memory, `.remember`) — durable context and decisions (the
  *why*), never open tasks.

Shipped work is the git history + closed issues; this file no longer tracks it.
